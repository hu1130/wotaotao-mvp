# 2026-07-20

## 问题

超级管理员页面删除客户端后，客户端列表里仍显示该租户。

## 原因

删除客户端控制面数据时不会硬删除租户管理员账号，而是停用账号以保留审计边界。客户端列表聚合时把已停用管理员账号也作为客户端存在依据，导致设备和激活码已清空后仍显示“空壳客户端”。

## 修改方案

平台客户端列表只显示仍有活跃管理员、注册设备或激活码记录的租户。已执行删除、仅剩停用管理员账号的租户不再出现在列表中。

## 影响

删除客户端后页面刷新会从列表移除该租户。不会改变删除动作本身：仍然不删除员工、考勤、人脸向量、知识库或人物记忆。

## 验证

- 新增单测覆盖仅剩停用管理员账号时不展示客户端。
- 执行客户端管理服务相关单测和 Python 编译检查。
