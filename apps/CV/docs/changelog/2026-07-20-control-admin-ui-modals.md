# 2026-07-20

## 问题

控制台运行页把“前台展示形态”“数字人实例”“数字人人设”拆成多个平级卡片，层级不符合实际操作关系；超级管理员查看客户端详情时在列表下方展开，占用主页面空间。现有卡片圆角偏硬，整体观感较方。

## 原因

前台展示形态是数字人实例是否可见的上层状态：选择数字人时才需要展示五个 Live2D 实例，选择漩涡前台时实例选择不应继续占位。数字人人设和客户端详情都是低频编辑/查看任务，更适合弹窗承载，而不是长期占据页面布局。

## 修改方案

- 将前台展示形态选择移入“前台与数字人实例”区域顶部，移除独立展示形态卡片。
- 根据当前前台形态控制实例列表可见性：数字人展示五个实例，漩涡前台隐藏实例列表。
- 将数字人人设表单改为按钮打开的弹窗，保留保存、恢复默认和状态提示。
- 将超级管理员客户端详情改为列表内点击“查看”后弹窗展示，弹窗内保留管理员、激活码、注册机器和删除/新增激活码操作。
- 将主要卡片和控件圆角统一到更自然的 8px 视觉尺度。

## 影响

只影响控制台和超级管理员页面的前端布局与交互，不改变平台 API、租户隔离、设备注册或激活码逻辑。

## 验证

- 运行 `node --check server_deploy/avatar/control.js`。
- 运行 `node --check server_deploy/avatar/super-admin.js`。
