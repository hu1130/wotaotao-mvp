# 2026-07-21 漩涡自然能量动效调整

## 问题

漩涡中心视觉在状态切换时旋转过快、变化突兀，待机、倾听、思考、回答之间像直接切换档位，不符合自然增加和自然衰减的观感。

## 原因

导入版漩涡 shader 主要通过离散的 `mode` 值直接驱动旋涡速度、半径和颜色。`mode` 的语义是状态枚举，不是连续能量值，因此运行时状态包快速变化时，视觉层会出现乱转和跳变。

## 修改方案

`frontend_sources/imported-vortex-frontdesk/components/fluid-orb.tsx` 增加连续动效层：

- 新增 `energy`、`answer`、`listening` 三个连续动态参数。
- 待机状态保持低能量，黑色气旋更少、更淡。
- 人物说话时能量逐渐上升，气旋密度温和增加。
- 数字人开始回答时能量进入高位，黑色气旋更多，中心紫色物质流动速度更快。
- 回答结束后使用较慢 release 曲线自然衰减，避免突然收缩或乱转。
- shader 不再直接使用离散 `mode` 参与旋涡公式，`mode` 只在 React 侧换算连续目标能量。

## 影响

只影响导入版漩涡前台的 Three.js shader 视觉表现，不改变语音识别、回答生成、TTS 播放、状态栏字幕和数字人运行时状态机。
