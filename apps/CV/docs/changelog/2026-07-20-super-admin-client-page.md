# 2026-07-20

## 问题

客户端创建、激活码重置、注册机器删除等平台运维能力只存在于命令行工具中，控制台没有超级管理员页面；普通租户管理员页面只能管理本租户设备状态。

## 原因

现有系统已有租户管理员会话和 Node 侧平台能力判断，但 FastAPI 缺少平台管理员 API，CLI 的客户端管理逻辑也没有沉到可复用的服务层。

## 修改方案

- 新增 `core.client_admin.ClientAdminService`，统一复用创建客户端、生成激活码、重置密码、删除客户端控制面数据和设备管理逻辑。
- 新增 `/api/v1/platform-admin/*` 平台管理员接口，仅允许默认平台租户管理员会话或本地 legacy server credential 调用。
- 新增 `/super-admin.html`、`super-admin.js`、`super-admin.css`，用于创建/删除客户端、查看/新增激活码、重置管理员密码、启停/删除注册机器。
- Node 控制台新增 `/platform-admin/*` 代理和 `/super-admin.html` 平台权限保护，并在平台管理员可见区域加入入口。

## 影响

超级管理员可以管理所有客户端控制面数据。删除客户端只删除激活码、注册设备和设备会话，并可停用租户控制台管理员；不会删除员工、考勤、人脸向量、知识库或人物记忆。历史激活码仍只保存哈希，页面只能显示前缀和状态；完整激活码仅在创建客户端或新增激活码时返回一次。新增激活码不改变旧激活码状态。

## 验证

- 新增并运行平台管理员接口边界测试。
- 执行 Python 编译检查和 Node 语法检查。
