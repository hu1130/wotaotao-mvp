# 2026-07-20

## 问题

控制台从数字人切换到漩涡前台，再切回数字人后，数字人状态栏出现在左下角而不是展示模式的正中间。

## 原因

数字人页面依赖 URL 中的 `display` 参数给 `body` 添加 `display-mode`，状态栏居中样式也依赖这个 class。前台形态从漩涡切回数字人时，跳转目标只带了 `model`，没有保留 `display=1`，导致页面回到普通布局。

## 修改方案

切回数字人时，如果当前处在前台展示形态或已有 `display` 参数，则在目标 URL 中保留 `display=1`。

## 影响

仅影响前台形态切换后的数字人展示布局，不影响普通数字人页面和模型切换逻辑。
