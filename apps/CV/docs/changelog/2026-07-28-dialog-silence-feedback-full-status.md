# 2026-07-28

## 问题

测试数字人静音和解除静音时，语音反馈和状态栏都能正常出现，但用户感知到状态文字与实际播报内容对不上。

## 原因

静音反馈已经走 Omni 动态生成，并且后端下发给浏览器的 `llm_delta` 与 `tts_audio.text` 属于同一轮文本。问题发生在 avatar 播放层：实时语音播放状态会根据音频播放进度调用 `speechStatusTextAt`，把较长文本按句子或逗号切成当前播放片段显示。这个策略适合普通长回答，但静音/解除静音属于短控制反馈，播放期间应该显示完整动态话术，否则会出现耳朵听到完整句、状态栏只显示局部片段的错觉。

## 修改方案

为 `voice_turn_policy.speechStatusTextAt` 增加 `keepFullText` 选项。avatar 在静音控制反馈播放期间启用该选项，并使用当前反馈文本作为显示真值；普通实时沟通和固定语音仍沿用原播放进度切片策略。

## 影响

影响 avatar 前端状态栏显示。静音/解除静音反馈播放期间会完整显示动态话术，播放结束后仍按原逻辑恢复为“静音中...”或短暂显示解除静音状态；普通长回答不受影响。

## 验证

已添加 `voice_turn_policy` 单元测试覆盖短控制反馈完整展示。
