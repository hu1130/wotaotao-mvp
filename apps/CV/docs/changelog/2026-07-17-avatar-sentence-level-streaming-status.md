# 2026-07-17 数字人回答状态栏句子级流式优化

## 问题

回答播报时，状态栏原先按播放进度逐字截断显示。实际观感会出现单字跳动、半句话停留、标点附近截断不自然等问题，不像人与人对话时的字幕节奏。

## 优化方案

将回答状态栏从“字级渐显”调整为“句子级流式”：

1. 仍按句号、问号、感叹号、分号切成自然句。
2. 长句继续按逗号和最大长度切成可读短段，避免状态栏塞满整段文字。
3. 播放进度只负责选择当前句/短段。
4. 当前句/短段始终完整展示，不再逐字显示。
5. 播放进度刷新间隔从 500ms 调整为 250ms，让句子切换更及时。

这样状态栏会像字幕一样按句更新，减少跳字感，同时仍能跟随语音播放进度。
