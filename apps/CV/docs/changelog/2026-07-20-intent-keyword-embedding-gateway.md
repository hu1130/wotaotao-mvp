# 2026-07-20 意图关键词与 embedding 网关

## 问题

个人记忆、闲聊和公司业务问题原先主要混在 RAG 路由中判断。少量个人规则能拦截典型表达，但没有形成清晰的三类意图网关，语义相近但没有命中关键词的表达仍可能被错误分流。

## 原因

旧链路把“意图分类”和“企业知识库是否命中”耦合在一起。个人意图和公司业务意图都可能包含“什么、怎么、哪些”等问句特征，只靠关键词无法覆盖自然表达。

## 修改方案

- 在共享 `DialogIntentRouter` 中加入 `chat / personal / company` 三类意图。
- 路由顺序改为：
  1. 明显 ASR 残片直接释放为聊天，避免半句话打知识库。
  2. 关键词先粗筛常见闲聊、个人记忆、公司业务。
  3. 关键词未命中时，用 embedding 对比内置的闲聊、个人记忆、公司业务语料。
  4. embedding 低于阈值或不可用时，默认走公司知识库。
- 服务端文本对话和 Omni 实时语音共用同一共享路由。
- 日志增加 `intent` 字段，便于排查是关键词命中、embedding 命中还是默认公司知识库。

## 影响

闲聊和个人记忆问题会更稳定地留在聊天通道；公司业务问题和无法判断的问题默认进入企业知识库。企业知识库仍负责最终资料检索和回答，不使用意图 embedding 结果作为回答依据。

## 验证

新增意图路由测试覆盖关键词命中、embedding 命中、embedding 低分默认公司知识库，以及公司范围问题继续进入知识库。
