# 修复“昨天聊了啥”按最近两句回忆

- 根因：个人上下文回忆只倒序读取最近会话消息，没有解析“昨天/今天/前天”等日期词；当用户问“我们昨天聊了啥”时，会误把刚刚的几句当成目标内容。
- 现象：日志显示 `conversation_recall` 命中，但只使用最近上下文；线上 2026-07-22 有完成轮次，日总结尚未生成，因此原逻辑没有可用的日期回退。
- 修复：扩展 recall intent 的日期词识别；日期回忆优先读取对应日期的个人日总结，缺日总结时回退到当天已完成、可记忆的对话轮次。
- 状态：确定性个人回忆/身份回复在发送 `chat_tts_text` 前会主动中断 Omni 默认生成通道，避免状态栏先进入默认回答再切到确定性回答。
- 验证：新增/更新个人上下文、个人记忆服务和 Omni 分流测试；本地编译相关 Python 文件通过。
