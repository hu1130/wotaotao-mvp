# 2026-07-17 Agent 规则重构

## 问题

原 `.codex/AGENT.md` 同时承载工程规则、项目知识、部署命令、数据库说明和回复风格要求，导致核心行为约束被大量手册内容淹没。

## 原因

Agent 入口文件职责过多，缺少规则优先级和任务模式索引。架构、部署和领域知识没有与执行规则分离。

## 修改方案

- 新增根目录 `AGENTS.md` 作为标准入口索引，`AGENT.md` 保留为兼容入口。
- 重写 `.codex/AGENT.md`，聚焦角色定位、规则优先级、强制分析模板、禁止行为和核心不变量。
- 新增 `docs/architecture/system-design.md` 承载项目定位、目录职责和重要业务链路。
- 新增 `docs/deployment/deployment-guide.md` 承载同步、部署、打包和验证命令。
- 新增 `.codex/rules/04-security-and-boundaries.md` 承载安全、租户、设备和基础设施边界。
- 删除工程入口中的人格称呼要求。

## 影响

后续 Agent 可以先读取短入口和规则文件，再按任务加载架构或部署文档，减少上下文噪音并提升执行一致性。

## 验证

本次为文档重构，验证重点为 Markdown 文件存在性、关键引用路径和 Git diff 检查。
